RetailPulse: SQL-Based Inventory Management

Developed by: Arya Sankhalkar

Project Overview
I built RetailPulse to simulate a real-world retail database environment. The goal was to move beyond simple tables and implement a system that handles data integrity and automation internally. This project manages customers, products, and sales transactions while ensuring the data remains clean and organized.

Key Technical Features

Database Architecture: Designed using 3rd Normal Form (3NF) to eliminate data redundancy and ensure efficient storage.

Automated Inventory: Implemented a SQL Trigger (sy_stock) that automatically updates product stock levels whenever a new sale is recorded.

Data Integrity: Used Primary Keys, Foreign Keys, and Check constraints (like limiting cities to specific Goan locations) to prevent "garbage" data from entering the system.

Business Analytics: Includes a suite of custom queries to track high-value customers, identify unsold inventory, and analyze sales trends by city and month.

Why this matters
This project demonstrates my ability to bridge the gap between theoretical database concepts and practical application, specifically focusing on automation and reliable data structures.
